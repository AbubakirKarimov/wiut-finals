# ComplianceRadar — правила для агента

Система для службы ЦБ Узбекистана по защите прав потребителей: проверяет публичные сайты
банков на соответствие Положению ЦБ №3030 и Закону «О государственном языке» и находит
ВОЗМОЖНЫЕ НЕСООТВЕТСТВИЯ с доказательствами. Решение принимает аналитик ЦБ.

Код, имена, комментарии — на английском. Интерфейс и отчёты — на русском.

## Жёсткие правила (нарушение = дисквалификация проекта)

- Никаких захардкоженных ответов, моков вместо рабочих функций, выдуманных метрик и чисел.
  Нет данных -> пиши «нет данных». Цену LLM и любые цифры берёшь из конфига или логов.
- Статус находки только `possible_gap` (возможное несоответствие), никогда «нарушение».
  Не уверен -> `not_checkable`.
- У каждой находки есть доказательство: URL, дословная цитата, id пункта закона. Цитата ОБЯЗАНА
  дословно встречаться в тексте страницы (после нормализации пробелов): проверяй кодом,
  иначе статус `not_checkable`.
- Только публичные страницы. Соблюдай robots.txt, не чаще 1 запроса в секунду на домен,
  User-Agent с названием проекта. Персональные данные, номера карт и телефоны не собирай.
- Если сайт или lex.uz блокирует бота, НЕ обходи защиту: запиши в отчёт и спроси пользователя.
- Секреты только в `.env` (есть `.env.example`), в код и коммиты не попадают.
- Прежде чем писать код этапа, коротко напиши план. После этапа: запусти тесты, покажи вывод,
  сделай коммит, дай отчёт в 5 строк. Не говори «работает», пока не запустил.
- Места с пометкой СТОП: остановись и жди ответа пользователя.
- Новый репозиторий не создавать, `git push` не делать. Коммитить локально после каждого этапа.

## Стек

Python 3.11 (`.venv`), FastAPI, httpx, Playwright (chromium), BeautifulSoup4, pdfplumber,
pydantic v2, SQLite, pytest, PyYAML. Frontend: React + Vite.
LLM только через класс `LLMProvider` (`ApiProvider`, `LocalProvider` на Ollama); модель, ключ и
адрес — из `.env`, названия моделей в код не зашивать.

## Команды

- Установка: `python3.11 -m venv .venv && .venv/bin/pip install -r requirements.txt`
- Тесты: `.venv/bin/pytest`
- API: `.venv/bin/uvicorn backend.api.main:app --reload`
- Frontend: `cd frontend && npm install && npm run dev`
